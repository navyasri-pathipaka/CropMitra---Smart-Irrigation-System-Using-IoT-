# CropMitra---Smart-Irrigation-System-Using-IoT-
🌱 CropMitra is an IoT‑enabled smart irrigation system that automates water management using real‑time soil &amp; weather data. 🔧 Built with NodeMCU ESP8266, sensors &amp; relay pump, 💻 programmed in Arduino IDE with a web dashboard (HTML/CSS/JS). 🌾 Ensures optimal irrigation,  live monitoring,  weather‑adaptive scheduling, sustainable farming.
